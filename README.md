# 📦 CSS Box Model Demonstration (Margin, Border, Padding)

A visual and interactive educational project built using HTML and CSS to clearly demonstrate the core concepts of the **CSS Box Model** (Content, Padding, Border, and Margin)[cite: 3].

## ✨ Features

* **🎨 Nested Box Layout:** Utilizes a nested multi-container layout (`div` blocks) with distinct background colors (teal, sky blue, navy blue, royal blue, and orange) to represent different layers of the box model[cite: 3].
* **📏 Spacing & Positioning:** Showcases precise CSS property implementations including custom margins, thick borders, and padding offsets[cite: 3].
* **📍 Visual Labels:** Features absolute positioning labels (`margin`, `border`, `padding`) overlaid to clearly point out each structural boundary[cite: 3].

## 📂 File Structure

* `Margin & padding.html` - The single-file project containing the nested layout structure and embedded CSS styles[cite: 3].

## 🚀 How to Use

1. Download or clone the repository.
2. Open `Margin & padding.html` in any modern web browser to visually inspect how margins, borders, padding, and content interact within the browser layout[cite: 3].
